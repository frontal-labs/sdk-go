# Changelog

All notable changes to this SDK are recorded here.

## [1.0.0] - 2026-10-08

- Add the unified `frontal.New` client and service namespaces for the full endpoint inventory.
- Add context-first contract calls, request IDs, environment headers, configurable retries, pagination metadata, polling, and cancellable SSE channels.
- Add typed API errors, category helpers, raw/form-data operation support, and tests backed by `httptest.Server`.
- Add Go 1.22/1.23 CI, gofumpt/goimports/golangci-lint checks, contract drift validation, Conventional Commit hooks, and GoReleaser tag releases.
