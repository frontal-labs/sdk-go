# Security policy

Report vulnerabilities privately to **security@frontal.dev**. Include the affected SDK version, Go version, reproduction steps, impact, and a proof of concept when possible. Do not include API keys or customer data. Do not open a public issue for an unpatched vulnerability.

Never commit populated `.env` files, credentials, or captured production payloads. Security fixes are provided for the latest supported major release, currently v1. Older major versions are unsupported unless explicitly stated in a release notice. Go 1.22 and 1.23 are the currently tested toolchains.
